# 🏗️ Event-Driven Order Processing System

Event-Driven система из 5 микросервисов для асинхронной обработки заказов.

## 🏗️ Архитектура (5 микросервисов)

| Сервис | Функция |
|--------|---------|
| API Gateway | Принимает заказы, возвращает мгновенный ответ |
| Order Processor | Асинхронно обрабатывает заказы, retry 3 раза |
| Event Store | Полный аудит и трассировка |
| Send Notification | Email/Telegram/SMS уведомления |
| Dead Letter Queue | Отлов упавших задач |

## ✅ Ключевые преимущества

- Гарантированная доставка 100% заказов
- Мгновенный ответ клиенту
- Отказоустойчивость из коробки

## 🛠 Технологии

n8n | Webhook | Queue | Event Store
